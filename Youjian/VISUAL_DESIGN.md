## 1. 视觉概念

核心意象是“一盏灯圈出一块属于自己的光”。

- 灯未亮：准备开始，不制造焦虑；
- 暖光亮起：正在专注；
- 蓝灰收暗：短暂暂停；
- 多盏灯同时亮起：朋友在不同地方做不同的事，但共享同一段专注氛围。

整体气质：安静、温暖、克制、可信，不使用游戏排行榜式刺激，也不制作企业效率工具式密集仪表盘。

## 2. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `color-bg` | `#F7F3EA` | 页面暖象牙背景 |
| `color-text` | `#2C2A25` | 主文字与计时数字 |
| `color-primary` | `#F5C96A` | 点亮、专注、主按钮 |
| `color-primary-soft` | `#FFF6DE` | 暖光区域和浅色卡片 |
| `color-pause` | `#82909D` | 暂停状态 |
| `color-warning` | `#FF8A3D` | 连接不可确认和临近自动结算 |
| `color-success` | `#4CAF7B` | 完成打卡和达成目标 |
| `color-surface` | `#FFFCF6` | 主卡片表面 |
| `color-border` | `#E8E0D3` | 细边框和分隔 |

规则：

- 暖黄只表达正在专注或主要行动；
- 蓝灰只表达暂停，不用于普通信息卡；
- 橙色不等于错误，只表达需要注意的连接或时间状态；
- 红色只用于停用成员、重置邀请等破坏性操作；
- 所有文字对比度在实际实现中单独验证，不因效果图而降低。

## 3. 字体与数字

建议字体栈：

```css
font-family: Inter, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```

层级：

| 用途 | 建议字号 | 字重 |
|---|---:|---:|
| 大计时 | 52px | 500 |
| 页面标题 | 24px | 650 |
| 任务名称 | 22px | 650 |
| 卡片标题 | 16px | 600 |
| 正文 | 14px | 400 |
| 辅助信息 | 12px | 400 |

计时数字使用 tabular numbers，防止秒数变化导致宽度跳动。中文正文不使用过细字重。

## 4. 形状与空间

- 基础间距单位：4px；
- 页面左右边距：16px；
- 常用区块间距：16px 或 24px；
- 主卡片圆角：18px；
- 小卡片圆角：14px；
- 按钮圆角：16px；
- 主按钮高度：52px；
- 阴影：低对比、短距离，不制造悬浮玻璃效果；
- 边框：1px 暖灰，仅在浅色表面层级不足时出现。

## 5. 台灯与光圈

台灯是状态符号，不是装饰插画。

### 空闲

- 米白灯体；
- 无明显灯束；
- 使用低对比圆形背景界定位置；
- 不表现失败或熄灭惩罚。

### 专注

- 灯头发出暖黄光；
- 桌面形成横向椭圆光域；
- 光域亮度低于主按钮，不影响任务和计时阅读；
- 可以有非常轻的呼吸变化，但默认静止也成立。

### 暂停

- 整体转为蓝灰；
- 灯光收暗；
- 保留灯的轮廓，表达“暂时离开”而非“记录消失”；
- 不使用红色、叉号或失败图形。

实现时优先使用原创 SVG／CSS 图形或项目内正式导出的灯素材，不能直接把整张视觉方向稿切图当作页面。

## 6. 核心组件

### 主按钮

- 专注相关主操作使用暖黄；
- 暂停页的“继续专注”使用蓝灰底白字；
- 同一屏只存在一个主按钮；
- 加载时保留宽高，文字替换为状态说明。

### 次操作

- “结束本次”使用文字按钮；
- 与主按钮保持至少 12px 间距；
- 不使用同等面积和色彩，降低误触。

### 好友专注卡

- 左侧为小型灯光状态图；
- 中间为昵称、任务和分类／时长；
- 右侧小圆点只表达当前同步状态；
- 不显示头像、排名、点赞或聊天入口。

### 今日摘要

- 一行显示今日累计、距离打卡和连续天数；
- 移动端不足 360px 时允许换成两行；
- 数字略重于标签，但不超过任务标题。

### 底部导航

- 首页、统计、目标、设置四项；
- 当前项使用暖黄图标和文字；
- 非当前项使用中性灰；
- 图标必须有文字标签，不能只靠图形判断。

## 7. 三种首页状态

### 空闲

视觉重点：今天进度 → 未点亮台灯 → 开始专注 → 好友状态。

主按钮文案：“开始专注”。

### 正在专注

视觉重点：暖光台灯 → 当前任务 → 大计时数字 → 暂停。

页面应比空闲状态更集中，今日摘要移到次要位置。

### 暂停

视觉重点：蓝灰暂停卡 → 暂停倒计时 → 继续专注。

倒计时必须同时说明自动结束后果，不只显示数字。

## 8. 动效

- 页面切换：150–200ms 淡入／位移；
- 开始专注：灯光在 250ms 内亮起；
- 好友卡加入／移除：180ms 淡入淡出；
- 全员打卡：不超过 1.5 秒的多灯光圈；
- 暂停剩余一分钟：只改变强调色，不闪烁；
- 支持 `prefers-reduced-motion`，关闭所有非必要动画。

## 9. V1 评估

方向稿已验证：

- 空闲、专注、暂停状态可明显区分；
- 暖黄与蓝灰的状态语义清楚；
- 台灯和光圈可以成为稳定品牌符号；
- 好友可以做不同任务，信息层级仍然清晰；
- 主操作和次操作权重明确；
- 视觉没有引入任务清单、聊天或排行榜。

进入代码前仍需在确认本方向后补充：

- 创建／邀请页高保真稿；
- 统计页和目标页高保真稿；
- 连接不可确认和自动结算状态；
- PWA 图标与正式台灯素材；
- 深色模式不属于 MVP。
