## 验收步骤

每项都记录北京时间、结果和截图编号。发生失败时保留页面，不要清理浏览器数据，先记录错误文字和操作顺序。

| # | 操作 | 预期结果 | iPhone | Android | 证据 |
|---|---|---|---|---|---|
| 1 | 两台手机分别直接打开目标地址 | HTTPS 页面可访问，不要求 GitHub 或 ChatGPT 登录 |  |  |  |
| 2 | iPhone 创建友间并输入昵称 | 创建成功，进入同一设备持久化的匿名身份 |  | 不适用 |  |
| 3 | 房主从设置复制邀请，Android 点击邀请并加入 | Android 只看到邀请预览；加入后双方进入同一友间 |  |  |  |
| 4 | 两人分别开始不同任务 | 数秒内双方都看到对方亮灯状态 |  |  |  |
| 5 | 房主暂停，锁屏 2 分钟后返回 | 暂停时间不增长；页面先完成服务端同步再允许继续 |  | 不适用 |  |
| 6 | 成员专注中锁屏 2 分钟后返回 | 计时按服务端时间追平，不因浏览器冻结而少算或多算 | 不适用 |  |  |
| 7 | 房主恢复并在实际专注满 5 分钟后结束 | 结果至少 5 分钟；暂停的 2 分钟不计入 |  | 不适用 |  |
| 8 | 打开统计页并切换日／周／月 | 历史记录存在，三个周期均能加载且无跨房间数据 |  |  |  |
| 9 | 房主发起共同目标，成员同意 | 提案显示全员通过，并标明下一完整周期生效 |  |  |  |
| 10 | 房主轮换邀请，再打开旧邀请 | 新链接可复制；旧链接立即显示失效且不能加入 |  |  |  |
| 11 | Safari“添加到主屏幕”、Chrome“安装应用” | 图标正确；从桌面图标启动后为 standalone 模式 |  |  |  |
| 12 | 完全关闭 PWA 后重新打开 | 两台设备都恢复原匿名身份、友间和当前状态 |  |  |  |
| 13 | 切换 Wi-Fi／蜂窝网络或短暂断网后恢复 | 离线时不伪造操作成功；恢复后 Realtime 重新同步 |  |  |  |
| 14 | 检查 320px 等效窄屏、横屏和系统 200% 字体 | 无关键横向滚动，主要按钮可点击，焦点不被底栏遮挡 |  |  |  |
